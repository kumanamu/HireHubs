## 1. Project Overview

HireHubは、求職者と企業をつなぐ
Webベースの採用プラットフォームです。

求人管理、ユーザー認証、決済基盤サービス、
AI分析機能などを含むチームプロジェクトとして開発されました。

本プロジェクトでは、
バックエンドおよびインフラ領域を中心に、
主要機能の設計・実装・配布・運用を担当しました。

## 3. Key Contributions (Core Features)

### Authentication & Security

- JWTベースの認証構造を設計・実装  
- Google、Kakao、Naverのソーシャルログイン連携を担当  
- Spring Securityを用いた認可ポリシーおよびCORS設定  
- トークン発行・検証・有効期限管理を分離して設計  

---

### Payment & Token System

- PortOne（KGイニシス）決済モジュールを連携  
- テスト環境と本番環境を分離した決済フローを設計  
- トークンパッケージ、決済履歴、ステータス管理を実装  
- 決済成功時のデータ不整合問題を分析・修正  

---

### AI Analysis API

- FastAPIベースのAI分析サーバーを連携  
- SSE（Server-Sent Events）によるストリーミング応答処理  
- Basic分析およびPremium分析を分離して設計  
- 多言語トグルを考慮したレスポンス構造を設計  

---

### Map & Location Feature

- Kakao Map APIを連携  
- 住所入力時に緯度・経度を自動保存する仕組みを実装  
- APIキーおよびドメイン認証に関する問題を解決  
- 将来的な位置情報拡張を考慮したエンティティ設計  

---

## 4. Problems & Debugging

開発および配布の過程で、以下の問題を直接分析・解決しました。

- 認証トークン未送信による401エラーの原因分析および修正  
- CORS設定漏れによるフロントエンド通信遮断の解決  
- DockerおよびNginx環境におけるパス設定エラーの修正  
- SSE接続中に発生した404／401エラーの分析  
- 環境変数不足による配布エラーの解消  
- DTO変更によるフロントエンド描画エラーの修正  

ログを基準に原因を追跡し、
再現可能な形で修正することを原則としました。

---

## 5. Deployment & Operation

- DockerおよびDocker Composeによるサービス環境構築  
- Backend／Frontend／AIサーバーのコンテナ分離運用  
- GitHub Actionsを用いたCI/CDパイプライン構築  
- EC2およびNginxを用いた配布環境構成  
- `.env.prod`による環境変数の分離管理  
- 配布後はログを基にしたエラー監視と対応  

---

## 6. Lessons Learned & Future Improvements

### Lessons Learned

- チームプロジェクトでも個人の責任範囲を明確にする重要性  
- ローカル環境と本番環境の差を考慮した設計の必要性  
- 認証・決済・AI機能では例外を前提とした設計が不可欠  
- フロントエンドとバックエンド間の明確なコミュニケーションの重要性  

### Future Improvements

- 認証および権限構造の高度化  
- 決済システムの例外処理およびログ管理強化  
- AI分析レスポンスの性能改善  
- モニタリングおよび通知システムの導入
